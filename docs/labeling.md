# 标注工具说明

## 为什么需要人工标注

方案③（像素级分类器）用弱标签训练过两版，都失败了：把检测框当正样本会把框角的木纹教成前景；把检测掩膜当正样本则只覆盖纸币的 1.8%–4%，未检出部分被标成背景。**用弱检测器训练新检测器只会复制它的错误**。详见 `docs/validation_log.md` 的「方案③」一节。

## 启动

```bash
python scripts/label_tool.py --folder data/raw/self --pattern "s*.jpg"
# 从第 6 张开始（0 基）
python scripts/label_tool.py --folder data/raw/self --pattern "s*.jpg" --start 5
```

窗口宽度自动缩放到 1400px 以内，坐标会换算回原图尺寸保存。

## 按键

| 操作 | 作用 |
|---|---|
| 左键 | 多边形模式：加一个顶点 |
| 右键 / 回车 | 闭合当前多边形（至少 3 个点） |
| `Backspace` | 撤销上一个顶点；无顶点时撤销上一个标注 |
| `r` | 切换矩形模式：按住左键拉框，松开完成 |
| `u` | 删除最后一个标注 |
| `d` / `→` | 下一张（自动保存） |
| `a` / `←` | 上一张（自动保存） |
| `s` | 立即保存 |
| `q` / `Esc` | 退出（自动保存） |

## 标注规范

1. **只标目标的可见轮廓**，不要把阴影、桌面、手表、充电器算进去；
2. **被遮挡的部分按可见部分闭合**，不要凭空补全；
3. 纸币和硬币都标，硬币用矩形模式更快；
4. **叠放的纸币要分开标**，一张一个多边形——这正是当前算法最需要学习的地方；
5. 边缘尽量贴紧票面，误差控制在 2–3 像素内即可。

## 标多少

- **4–5 张**足够训练一个 9 维特征的随机森林；
- 尽量覆盖不同光照与摆放，其中至少一张包含硬币；
- 单张 3–4 个目标，约 1–2 分钟一张，总计 10 分钟左右。

## 产物

```
data/raw/annotations/
├─ labels.json          每张图的多边形（原图坐标）
└─ masks/<stem>.png     0/255 掩膜（原图尺寸）
```

## 标完之后

```bash
# 用人工掩膜重训像素分类器（前 5 张训练、后 5 张测试）
python scripts/train_pixelclf.py --masks data/raw/annotations/masks
```

训练脚本会优先读取人工掩膜，没有时才退回弱标签（并在日志里标注 `[弱标签]`）。
注意：测试图也应标注，否则评估仍只能比"张数是否正确"。
